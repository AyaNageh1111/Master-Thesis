# Concept Grounding Problems in Concept Bottleneck Models (CBMs)

## Summary Table

| # | Problem                                     | Description                                                                                                                            | Example                                                                                                                                                                                       | Papers tried to solve it | Comments                                                                                                 |
| - | ------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------ | -------------------------------------------------------------------------------------------------------- |
| 1 | **Incorrect Concept Grounding**       | The model correctly predicts a concept but relies on evidence that does not actually represent it.                                     | A CBM predicts `red\_wing = True` because it detects a red flower behind a bird rather than the bird's red wing.                                                                            |                          | **What evidence** is the model using to recognize a concept?                                       |
| 2 | **Spurious Correlations**             | The model learns accidental relationships between concepts and irrelevant features, leading to unreliable predictions.                 | A CBM associates `cow\_present` with green grass because most training images show cows in fields. It fails to recognize a cow on a beach.                                                  |                          | Is the model relying on **irrelevant shortcuts** instead of the concept itself?                    |
| 3 | **Concept Leakage**                   | Concept activations encode additional information beyond their intended semantic meanings, compromising interpretability.              | The activation for `has\_wings` unintentionally contains information about the bird's species, allowing the classifier to exploit hidden information.                                       |                          | Does the concept representation contain **unintended hidden information**?                         |
| 4 | **Poor Spatial Localization**         | The model detects a concept but fails to identify the specific image region or object corresponding to it.                             | A CBM correctly predicts `red\_collar = True` for a dog but highlights the dog's entire body instead of its collar.                                                                         |                          | Improve pixel-level, patch-level, or object-level localization of concepts.                              |
| 5 | **Binding Errors**                    | The model identifies the correct objects and attributes but incorrectly associates attributes with their corresponding objects.        | An image contains a red car and a blue bicycle. The model detects all four concepts but incorrectly assigns red to the bicycle and blue to the car.                                           |                          | **Which object** does each concept or attribute belong to?                                         |
| 6 | **Lack of Grounding Evaluation**      | Conventional metrics, such as concept accuracy, cannot reliably determine whether concept predictions depend on the intended evidence. | Two CBMs achieve 95% concept accuracy. One detects a bird's actual red wing, while the other relies on correlated background features. Standard accuracy does not reveal the difference.      |                          | Develop standardized evaluation methods using localization metrics, interventions, and robustness tests. |
| 7 | **Temporal and Multimodal Grounding** | The model struggles to associate concepts with the correct time intervals or evidence from different modalities.                       | A video shows a person falling at second 8 and an unrelated crashing sound at second 12. The CBM predicts `person\_falling` based on the unrelated audio rather than the person's movement. |                          | Ensure concepts are grounded in the correct temporal segments, modalities, and corresponding events.     |
